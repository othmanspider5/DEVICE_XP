TECHVERSE — Website package
===========================

Files:
- index.html : page structure
- style.css : responsive White Modern design + dark mode
- script.js : product data, search, categories, sorting, language switch and comparison

How to run:
1. Extract TECHVERSE.zip.
2. Open the TECHVERSE folder.
3. Double-click index.html to open it in your browser.

Notes:
- The site uses online Unsplash image URLs and Google Fonts, so an internet connection is needed for those assets.
- Product prices/specifications are illustrative demo content, not live offers or verified current market prices.
- Languages: English, Arabic (RTL), French.
- No installation or build tools required.
